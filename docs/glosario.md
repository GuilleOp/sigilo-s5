# Glosario

| Español (dominio)    | Inglés (código) | Definición                                                          |
| -------------------- | --------------- | ------------------------------------------------------------------- |
| Denuncia             | complaint       | Reporte de faltas administrativas o hechos de corrupción.           |
| Persona denunciante  | reporter        | Quien presenta la denuncia.                                         |
| Persona denunciada   | accused         | Persona o cargo señalado en los hechos.                             |
| Autoridad competente | authority       | Autoridad investigadora que recibe la denuncia.                     |
| Folio                | folio           | Identificador público aleatorio de la denuncia.                     |
| Recibo               | receipt phrase  | Ocho palabras secretas que solo conoce la persona denunciante.      |
| Comprobante          | signed receipt  | Constancia firmada por el servidor de que la denuncia fue recibida. |
| Sobre                | envelope        | Mensaje cifrado con HPKE hacia una llave pública.                   |
| Identidad sellada    | sealed identity | Datos de la persona denunciante cifrados hacia la autoridad.        |
| Buzón                | mailbox         | Canal cifrado bidireccional entre autoridad y persona denunciante.  |
| Bitácora             | ledger          | Registro de solo agregar encadenado por hashes.                     |
| Prueba               | evidence        | Archivo aportado como soporte de los hechos.                        |
| Huella               | trace           | Dato que puede identificar a la persona denunciante.                |
| Limpieza             | sanitization    | Eliminación de metadatos y rastros de un archivo.                   |
| Semáforo de riesgo   | risk meter      | Indicador agregado del riesgo de reidentificación.                  |
