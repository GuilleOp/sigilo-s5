# Contribuir

1. Lee las [convenciones](docs/convenciones.md) y las [interfaces](docs/interfaces.md).
2. Crea una rama corta desde `main` con el prefijo correspondiente (`feat/`, `fix/`, `docs/`...).
3. Ejecuta `npm run hooks:install` una vez para activar las revisiones locales previas al commit.
4. Antes de abrir un pull request, ejecuta `npm run check`.
5. Describe en el pull request qué cambia, por qué y cómo se probó. Vincula el issue.

Nunca incluyas datos personales reales en código, pruebas, capturas o issues.
