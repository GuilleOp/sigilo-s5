# Mulish (autoalojada)

Tipografía de la dirección visual A. Archivos `woff2` tomados una sola vez del repositorio oficial
[googlefonts/mulish](https://github.com/googlefonts/mulish) (`fonts/webfonts/`, rama `main`,
descargados el 2026-11-05): Light (300), Regular (400), Italic (400), Bold (700), ExtraBold (800) y
Black (900).

Licencia: SIL Open Font License 1.1 (`OFL.txt`, copiado del mismo repositorio). Se distribuye sin
modificar. La web los sirve desde su propio origen (`styles/fonts.css`); nunca se piden a terceros
en tiempo de ejecución.
